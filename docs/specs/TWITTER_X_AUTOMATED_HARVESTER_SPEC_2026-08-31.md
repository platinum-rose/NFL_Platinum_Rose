**Date:** 2026-08-31
**Author:** Antigravity Engineering
**Audience:** Claude Team & Full-Stack Data Pipeline
**Target:** Automated harvesting of Twitter/X sharp betting picks, bookmarks, and tracked accounts into the weekly intel pipeline.

---

## 1. Executive Summary & Problem Clarification

### The Misconception:
*“Automating Twitter/X ingestion is a dead end without paying \$100+/mo for the X Developer API tier.”*

### The Reality:
X’s web frontend (`x.com`) communicates with its backend via standard **GraphQL endpoints** (`BookmarkSearchTimeline`, `UserTweets`, `ListLatestTweetsTimeline`) using ordinary HTTP `GET`/`POST` requests authenticated via standard web session cookies:
1. `auth_token` (HTTP-only session cookie generated when logging into a free X account).
2. `ct0` (CSRF token generated by X web client).

By utilizing these two free session tokens, a background daemon/cron agent can query X's internal GraphQL endpoints directly, fetching 100% of user bookmarks and tracked account timelines with **\$0 API costs**, zero paid subscriptions, and full fidelity (including full-text note-tweets, image attachments, and quoted status payloads).

## 3. How the GraphQL Ingestion Operates (Implementation Details)

### 3.1. Authentication Headers
The client issues standard `fetch()` requests mimicking a standard desktop browser:
```javascript
const headers = {
  'authorization': 'Bearer AAAAAAAAAAAAAAAAAAAAANRILgAAAAAAnNwIzUejRCOuH5E6I8xnZz4puTs%3D1Zv7ttfk8LF81IUq16cHjhLTvJu4FA33AGWWjCpTnA', // Public X Web Client Bearer
  'cookie': `auth_token=${process.env.PERSONAL_TWITTER_AUTH_TOKEN}; ct0=${process.env.PERSONAL_TWITTER_CT0};`,
  'x-csrf-token': process.env.PERSONAL_TWITTER_CT0,
  'user-agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
  'content-type': 'application/json',
};
```

### 3.2. Query Endpoints
1. **Personal Bookmarks:**
   - Endpoint: `https://x.com/i/api/graphql/ioP4Xb7LV__rVXS2f88ayg/BookmarkSearchTimeline`
   - Supports search parameters (`rawQuery: "NFL"`, `count: 20`).
2. **Tracked Sharp Account Timelines:**
   - Endpoint: `https://x.com/i/api/graphql/<queryId>/UserTweets`
   - Scrapes the latest tweets from curated list: `@WarrenSharp`, `@adamchernoff`, `@BradPowers7`, etc.

### 3.3. Multi-Modal Vision Extraction (Handling Screenshot Betslips)
When a sharp account posts a betslip screenshot or graphic (e.g. Nate's AlgoPicks or Circa ticket), the agent downloads the media image and passes it to **Gemini 2.0 Flash Vision**:
- **Prompt Schema:** Extracts `player_name`, `prop_type`, `line`, `side (OVER/UNDER)`, `odds`, and `team`.
- **Cost:** \$0 (Gemini 2.0 Flash free tier permits up to 1,500 requests/day).

## 4. Operational Guardrails & Stability

### 4.1. Cookie Lifetime & Expiry Management
- `auth_token` cookies issued by X typically stay valid for **6 to 12 months** unless explicitly logged out.
- **Auto-Health Check:** The agent tests session validity on every run. If a `401 Unauthorized` or `403 Forbidden` response is returned, it triggers a warning log:
  `[FATAL] Twitter session cookie expired. Please update PERSONAL_TWITTER_AUTH_TOKEN in .env.`

### 4.2. Rate Limiting & Polling Cadence
- Polling frequency is set to **every 15–30 minutes** (or on-demand prior to Sunday kickoffs).
- Request rate: ~5–10 requests per execution cycle, well below X's web client throttling thresholds (which allow hundreds of requests per 15-minute window per IP/user).

### 4.3. Deduplication & Idempotency
- Every tweet is keyed by its immutable Twitter `id_str` (e.g. `1828192837482`).
- Existing notes and pick signals in `research_pick_signals` are deduped using `${team_or_market}|${bet_type}` scoped to `note_id`.

## 5. Background Daemon / Service Execution

The harvester is registered as a background systemd timer or background Node worker:
- **Systemd Service:** `infra/systemd/nfl-twitter-bookmarks.service`
- **Systemd Timer:** `infra/systemd/nfl-twitter-bookmarks.timer` (runs every 20 minutes)
- **Manual / Ad-Hoc Command:**
  ```bash
  node agents/twitter-bookmarks-agent.js
  ```
