# Training Camp Manual Drops

Drop local training camp notes here for Phase 1 imports.

Supported inputs:

- Markdown with YAML frontmatter.
- Plain text with simple headers such as `Source:`, `Teams:`, and `Captured At:`.
- JSON arrays of structured `training_camp_intel` items.

Manual excerpts should stay short and source-stamped. This folder is local input for review snapshots, not a betting recommendation ledger.
